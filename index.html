НАСТРОЙКИ

Профиль, TMDB и общий доступ

Имя нужно, чтобы твои заявки и советы были подписаны и учитывались в рейтинге курьеров.
TMDB подключён централизованно через общий прокси — работает у всех, кто открывает сайт, без всякой настройки с их стороны. Поля ниже нужны только тебе как владельцу приложения — для отладки на своём устройстве, если решишь тестировать без прокси, напрямую своим ключом.
Важно: живой TMDB и Firebase заработают только на настоящем сайте (после того как выложишь файл на хостинг) — здесь, внутри предпросмотра Claude, сеть наружу заблокирована по соображениям безопасности, это норма.
Чтобы «Заявки» и «Кино-курьеры» были видны всем, а не только в этом браузере — создай бесплатный проект на firebase.google.com, включи Firestore Database и вставь сюда конфиг своего веб-приложения (Project settings → General → Your apps → SDK setup and configuration → объект firebaseConfig, целиком).
